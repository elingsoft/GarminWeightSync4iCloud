# 公众号发布包

这个目录保存公众号首发文章、封面、正文配图、发布参数和检查表。

## 文件

- `article.md`：公众号正文，可直接复制后重新排版。
- `publish-info.md`：标题、摘要、作者、阅读原文、关键词回复和发布检查表。
- `assets/`：封面、架构图、适用人群卡、部署检查卡和快捷指令截图。
- `generate_assets.py`：重新生成配图的脚本。

## 重新生成配图

```bash
./venv/bin/python marketing/wechat/generate_assets.py
```

## 推荐发布方式

使用普通推文，主标题采用 `佳明不读苹果健康的体重？我做了个免费开源工具`。先把正文粘贴到公众号编辑器，再按文中图片标记依次上传 `assets/` 中的图片。
